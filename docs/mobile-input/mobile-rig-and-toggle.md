# Runtime Platform Switching

Switching between Desktop and Mobile inputs can be toggled in real time via `MobileControlToggle.cs` without restarting the scene:

- Toggle the **TOUCH CONTROLS** checkbox on the gameplay HUD.
- The virtual control canvas activates instantly, hiding cursor lock handlers.
- Perfect for cross-platform debugging directly in the Unity Editor.
