# Creating a Custom Enemy

1. Ensure your monster model is rigged as a **Humanoid** in Unity import settings.
2. Open `Tools > AS1 > Suite Hub` -> **[AI] AI Creator Pro**.
3. Select an archetype preset (e.g. **Fast Runner**).
4. Assign your 3D model and Animator Controller.
5. Click **Generate Complete Zombie AI Prefab**.
6. Place the generated prefab into the scene or assign it to a `ZombieSpawner`.
